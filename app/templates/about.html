Predictive Maintenance System

Diagnostic Tool

This tool reads six measurements taken from an industrial machine and predicts whether it is at risk of failing soon, based on patterns learned from thousands of past machine readings.

Input Readings

Machine type
A build-quality grade — Low, Medium, or High. Select whichever category the machine falls into.
Air temperature (K)
The temperature of the air around the machine, in Kelvin — a scale similar to Celsius but starting from absolute zero. Room temperature is roughly 300K.
Process temperature (K)
How hot the machine runs internally while operating, also in Kelvin. Usually a few degrees above the air temperature.
Rotational speed (rpm)
How fast the machine's main spinning part turns, in revolutions per minute — the same reading as an RPM gauge.
Torque (Nm)
The twisting force the motor applies, in Newton-metres — in plain terms, how hard the motor is working.
Tool wear (min)
Minutes the cutting tool has been in use since it was last replaced. More wear increases failure risk.

Output Reading

Result
Normal or Failure Risk — a direct read on whether the entered values match the pattern of machines that failed.
Failure risk (aka) Confidence
How sure the model is, shown as a percentage — similar to a weather forecast's chance of rain. A high percentage is a strong warning, not a guarantee.
